# おくさん音量調節 Web版

ブラウザ内だけで音声の音量を調整し、WAVとして保存する静的Webアプリです。
音声ファイルはサーバーへ送信されません。

## 使い方

`index.html` をChromeまたはEdgeで開いてください。
PWAやオフラインキャッシュを有効にする場合は、HTTPサーバー経由で開きます。

```bash
python -m http.server 8080
```

その後 `http://localhost:8080` を開きます。

## 対応形式

入力はブラウザの `AudioContext.decodeAudioData()` が読み込める形式です。
一般にはWAV、MP3、M4A/AAC、OGGなどですが、OSとブラウザにより異なります。
出力は16bit PCM WAVです。

## 主な機能

- ドラッグ＆ドロップ、複数ファイル処理
- 1〜1000%の音量指定
- 音割れ防止コンプレッサー
- ピーク正規化（約 -1 dB）
- 完全ローカル処理
- PWA用マニフェストとサービスワーカー
